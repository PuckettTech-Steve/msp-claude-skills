# Content Log

The published-content record. Check before proposing topics (no topic repeats within 6 months;
same topic with a genuinely new angle is fine after that). Append a row when a piece is
finalized. When working from the installed plugin (read-only), output the row and ask the user
to add it here.

Status values: `drafted` (delivered to the owner, not yet posted), `published` (live), `retired`
(outdated; safe to redo).

**Source column:** `pack YYYY-MM` (a licensed marketing pack), `idea-bank`, `original` (the
owner's idea), or a URL for third-party inspiration.

Once real data exists (site analytics, listing views, social impressions), a performance column
can be added and fed into msp-metrics' monthly review.
